Magika.NET 命令行（Native AOT）

本目录是一次发布包。版本和平台写在 VERSION.txt。
程序是 Apache-2.0。standard_v3_3 模型已经嵌在二进制里，不需要再下载。
对应源码是本仓库里同名的 git tag。包里没有 .pdb / .dbg 调试符号。

Linux（在 ubuntu-latest 上构建，需要兼容的 glibc）:

  chmod +x magika
  ./magika --version
  ./magika example.pdf
  ./magika --json example.pdf

macOS（Apple Silicon / arm64，在 macos-latest 上构建）:

  chmod +x magika
  ./magika --version
  ./magika example.pdf
  ./magika --json example.pdf

下载后若被系统拦截，在终端执行 `xattr -d com.apple.quarantine ./magika`。

Windows:

  magika.exe --version
  magika.exe example.pdf
  magika.exe --json example.pdf

文本输出是「路径: 标签 分数 MIME 分组」。
--prediction-mode 可以是 high、medium 或 best-guess，默认 high。
--no-dereference 把符号链接标成 symlink，而不是跟随目标。
多个文件会并发读取，再按批推理。--batch-size 默认 8（1..64）。--workers 默认 0（每个处理器一条通道，没有上限）。
退出码：成功 0，找不到文件 1，参数错误 2。

English

This directory is one Native AOT release. The standard_v3_3 model is embedded.
Run ./magika <file> on Linux or macOS Apple Silicon, or magika.exe <file> on Windows.
If macOS blocks the downloaded binary, run `xattr -d com.apple.quarantine ./magika`.
Text output is "path: label score mime group", in argument order.
Several files are read concurrently and scored in batches. See --help for --batch-size and --workers.
