Magika.NET 命令行（Native AOT）

本目录是一次发布包。版本和平台写在 VERSION.txt。
程序是 Apache-2.0。standard_v3_3 模型已经嵌在二进制里，不需要再下载。
对应源码是本仓库里同名的 git tag。包里没有 .pdb / .dbg 调试符号。

Linux（在 ubuntu-latest 上构建，需要兼容的 glibc）:

  chmod +x magika
  ./magika --version
  ./magika example.pdf
  ./magika --json example.pdf

macOS（Apple Silicon / arm64，在 macos-latest 上构建）:

  chmod +x magika
  ./magika --version
  ./magika example.pdf
  ./magika --json example.pdf

下载后若被系统拦截，在终端执行 `xattr -d com.apple.quarantine ./magika`。

Windows:

  magika.exe --version
  magika.exe example.pdf
  magika.exe --json example.pdf

x64 有两份包。VERSION.txt 的 isa 是 avx2 或 avx512。
avx2 包需要 CPU 支持 AVX2。avx512 包需要 AVX-512，只有 AVX2 的机器跑不了。
macOS 包是 arm64，只有一份。VERSION.txt 的 isa 是 apple-m1（AdvSimd）。M 系列可以运行。

默认文本是「路径: 描述 (分组)」，与上游 Magika CLI 一致。
-r 递归识别目录中的文件。- 从标准输入读一次。-s 追加百分比分数，-i 打印 MIME，-l 打印标签。
--json 是 JSON 数组，--jsonl 是每行一个 JSON 对象。--format 使用 %p %l %d %g %m %e %s %S %b %%。
--prediction-mode 可以是 high、medium 或 best-guess，默认 high。
--no-dereference 把符号链接标成 symlink，而不是跟随目标。
多个文件会并发读取，再按批推理。--batch-size 默认 8（1..64）。--workers 默认 0（自动通道数）。
退出码：成功 0，有文件读不到 1，参数错误 2。-V 与 --version 相同。

English

This directory is one Native AOT release. The standard_v3_3 model is embedded.
Run ./magika <file> on Linux or macOS Apple Silicon, or magika.exe <file> on Windows.
x64 zips are split by instruction set. VERSION.txt isa is avx2 or avx512.
The avx2 build needs AVX2. The avx512 build needs AVX-512 and will not run on AVX2-only CPUs.
The macOS build is one arm64 binary. VERSION.txt isa is apple-m1 (AdvSimd). It runs on Apple Silicon.
If macOS blocks the downloaded binary, run `xattr -d com.apple.quarantine ./magika`.
Text output is "path: description (group)", matching the upstream Magika CLI.
-r walks directories, - reads stdin once, and -s/-i/-l/--json/--jsonl/--format follow upstream.
Several files are read concurrently and scored in batches. See --help for --batch-size and --workers.
-V is an alias of --version. Exit code 1 means at least one path failed; 2 means bad arguments.
